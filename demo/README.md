# Public demo data

Every file in this directory is fictional and was created specifically for the
public Dummy Data Lab V1.70 repository. Do not replace these files with internal,
operational, or production-derived data.

## simple-transform.csv

A 40-row introductory table with a fictional identifier, status, date, amount,
reserved-domain email, and optional notes. It is suitable for the Quick start
workflow and landing-page screenshots.

## business-transform.csv

A 240-row transformation demo designed to exercise:

- repeated entity references and reserved-domain emails;
- an intentionally imbalanced service category;
- dates, numeric amounts, statuses, and missing values;
- a stable service_code to service_name relationship that can be detected from
  row-level evidence and deliberately confirmed by the user;
- fictional_area and routing_bucket columns that vary independently and should
  not be treated as a relationship merely because their names sound related.

All areas, routes, references, services, tickets, and entities are invented.
There are no real addresses, telephone numbers, organisations, or events.

## related-tables-config.json

A source-free V1.70 Advanced configuration created through the current public
configuration serializer and the built-in connected scenario. It defines
People, Products, Orders, and Appointments tables with fictional generators,
keys, and dependent rules. It contains schemas and settings, not generated or
source rows.

## Safety rules

- Email addresses use the reserved example.invalid domain.
- Names and labels are explicitly fictional or generated by the application.
- No values were copied from local audit data, operational exports, screenshots,
  attachments, or private datasets.
- Before publishing an updated demo, scan it for credentials, personal domains,
  real addresses, local paths, and internal project names.
