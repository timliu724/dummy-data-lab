## Offline boundary

The standalone artifact contains its application code, styles, Papa Parse runtime, and Worker source.

Its Content Security Policy disables outbound connections. The packaged application does not use external scripts, styles, fonts, images, analytics, telemetry, or external source maps at runtime.

## Scope and limitations

V1.55 provides browser-local transformation and rule-based test-data generation.

It is not:

- certified anonymisation;
- a differential privacy implementation;
- a k-anonymity engine;
- a statistical or machine-learning synthetic-data model.

Text sanitisation is best effort. Only user-confirmed relationships receive strong generation and validation guarantees. High-fidelity output can preserve additional disclosure risk and should be reviewed before sharing.

See [Security and Privacy](SECURITY_PRIVACY.md) and [Known Limitations](KNOWN_LIMITATIONS.md) for the full boundaries.
