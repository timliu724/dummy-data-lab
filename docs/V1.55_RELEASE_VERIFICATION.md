## Release scope

V1.55 provides browser-local transformation and rule-based test-data generation.
It is not certified anonymisation, a differential privacy implementation, a
k-anonymity engine, or a statistical/ML synthetic-data model. Text sanitisation
is best effort, and only user-confirmed relationships receive strong generation
and validation guarantees.
